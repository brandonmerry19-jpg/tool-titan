# Tool Titan

Tool Titan is an affiliate-ready tool review and buying-guide website built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## Before launch

1. Replace `https://tooltitan.example` with the real domain in `app/layout.tsx`, `app/robots.ts`, and `app/sitemap.ts`.
2. Replace placeholder legal pages with reviewed, accurate business policies.
3. Add real business contact information.
4. Apply to affiliate programs and only add links after approval.
5. Add analytics/Search Console after the site is live.
6. Add original editorial content and verify product facts before publication.

## Deploy

Push this folder to GitHub, then import the repository into Vercel. Vercel will detect Next.js automatically.
